# To-Do-List

## Objective
To make a simple and basic To-Do list using Python for beginner.

## Tools
- Python
- Flask
- HTML
- CSS

## Key Insights
- Make a working To-Do list
- Should be functional
- Beginner friendly

## How it works
- First we create a virtual environment for the python file to work and import its library of Flask.
- Then make a good webpage using HTML.
- Finally style the webpage using CSS.
